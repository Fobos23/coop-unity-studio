# coop-unity-studio — студия кооп-игр на Unity для Windows

Навык Claude Code для кооп-игры на 2–8 игроков, где один игрок — хост (слушающий сервер): Unity 6, Netcode for
GameObjects 2.x, Unity Transport, Unity Relay (позже Steam). Вырос из опыта Zombolic: всё, что здесь записано,
однажды сломалось или было измерено на этой машине.

Владелец — режиссёр (вкус, объём, деньги, аккаунты, публикация, слияния), Claude — студия (всё остальное).
Главный принцип: **сначала сеть, проверка — на собранной игре**. Сетевой скелет и автотесты идут раньше контента,
у каждой карточки свой сценарий автотеста, действие клиента судится по тому, что видел клиент.

## Что взято из studioigor-skill

- **Фаза стиля** (фаза 2): направления с настоящими референсами на доске, 2–3 раунда отзывов, арт-библия,
  look-dev сцена из сборки. Если режиссёр приходит со своим арт-направлением, доски пропускаются, а библия и
  look-dev остаются. `refs.py` и `board.py` перенесены под MIT с правками для Windows и русским интерфейсом доски
  (`--lang ru`); лицензия — в `THIRD_PARTY_LICENSES.md`.
- **Джимы**: сцена на одну механику, ползунки по атрибуту `[Tune]`, одни и те же клавиши во всех джимах
  (R, Tab, O, P, 1/2, Shift+1/2, T). Для коопа — игра клиентом с `-netsim` (`gym.sh --coop`).
- **Таблица «ощущение в числах»** в `design.md`: общие ориентиры и строки для коопа, замеренные в Zombolic.
- **Gauntlet** — только для капсулы стора, первой минуты игры и главного кадра трейлера.
- **Обучение студии**: уроки копятся в очереди и попадают в навык только после «да» режиссёра; предпочтения
  «всегда / никогда» — для одной игры в её CLAUDE.md, для всех игр — в `learned/preferences.md`.

## Два правила, которых не было в Zombolic

- **Сначала установленные паки.** Перед тем как делать модель, текстуру, звук или анимацию — `find-packs.py`:
  что есть в `Assets/` и что лежит в кэше Asset Store. Подходящее предлагается владельцу. Паков нет или ни один
  не подошёл — делаем сами. Фактура — текстурами, износ — декалями, геометрия — только форма.
- **Smoke после карточки, полный регресс — после этапа.** После каждой карточки — её собственные сценарии и
  `run-suite.sh smoke` (smoke-сценарии каждого набора из `Tools/dev/autotests.txt`). Smoke упал в наборе, который
  карточка не трогала, — прогоняется этот набор целиком. Полный регресс `run-suite.sh full` — при закрытии ворот
  фазы, перед сборкой для людей вне студии (плейтест, кандидат в релиз), после обновления Unity, Netcode или
  Transport и по просьбе владельца.

## Установка

Навык личный: каталог (или ссылка на него) в `%USERPROFILE%\.claude\skills\coop-unity-studio`. Проще всего —
клонировать репозиторий прямо туда:
```
git clone https://github.com/Fobos23/coop-unity-studio "%USERPROFILE%\.claude\skills\coop-unity-studio"
```
Или клонировать куда удобно и поставить ссылку на эту папку:
```
mklink /J "%USERPROFILE%\.claude\skills\coop-unity-studio" "D:\Unity\coop-unity-studio"
```
Дальше в новом проекте: `/coop-unity-studio` и описание игры, или «продолжи игру» в существующем.

Для кадров из видео в фазе стиля (`refs.py youtube`) нужен yt-dlp:
```
winget install --id yt-dlp.yt-dlp -e
```
Вместе с ним winget ставит его сборку ffmpeg и Deno (без Deno YouTube не отдаёт поток); отдельный ffmpeg не нужен.
Папки программ попадают в PATH пользователя — уже открытые терминалы и приложения нужно перезапустить. Обновление —
`winget upgrade yt-dlp.yt-dlp`.

## Проверено

- `find-packs.py` на Zombolic: 14 паков в проекте, 19 из 27 загрузок Asset Store не импортированы.
- `extract-unitypackage.py`: импорт части пака с `.meta` и родными GUID, повтор ничего не перезаписывает.
- `run-suite.sh`: list, dry, smoke, full и suite на подставном раннере, включая повтор упавшего сценария (FLAKY),
  провалы клиентов и сценарий без SUMMARY.
- Хук pre-commit: самотест 34 из 34 (включая `hook.conf` с переводами строк CRLF); на 24 настоящих коммитах
  Zombolic ответы совпали с исходным хуком.
- C#-шаблоны (включая Gym.cs) компилируются (dotnet, netstandard2.1) с библиотеками Unity 6000.3.2f1, NGO 2.13.3,
  Transport и Input System: 0 ошибок, 0 предупреждений.
- `init.sh`: раскладка в пустой проект (25 файлов), повторный запуск ничего не меняет; правила `.gitignore`
  для `art/` проверены через `git status`.
- `refs.py`: Steam, Wikimedia и страницы по ссылкам скачиваются, картинки уменьшаются Pillow, палитра по лайкам
  считается. Openverse с этой сети закрыт проверкой Cloudflare — скрипт её не обходит.
- `refs.py youtube`: поиск по запросу, поток и 4 кадра 1280×720 за 30 с (yt-dlp 2026.10.26 с его сборкой ffmpeg и
  Deno 2.9.8 из winget).
- `board.py`: доска с русским интерфейсом открыта во встроенном браузере, отзыв дошёл до сервера и в
  `feedback.json`.
- `ab.py` / `reveal.py`: пара, отказ без вердикта и при повторном раскрытии, журнал раундов, лист кадров.
- `learn.py`: очередь, отсев повторов, принять / применить / отклонить, предпочтения для игры и общие.
